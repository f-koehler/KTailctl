# KTailctl v0.22.4

A patch release improving tray menu compatibility and stability, plus internal dependency and tooling updates.

## Fixes

- Fix tray menus and submenus (peers, exit nodes, accounts, …) not opening or closing immediately on Ubuntu/GNOME with the AppIndicator extension, by building the menus ahead of time instead of when they are opened (#689)
- Fix a crash in the tray menu when logged out or when the Tailscale daemon is not running
- Fix Kirigami navigation warnings; login profile details now open as a regular page (#630); thanks @ran-dall
